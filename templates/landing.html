Intelligent Brain MRI Analysis

NeuroInsight is a research platform that classifies brain MRI slices as glioma, meningioma, pituitary tumor or no tumor. It combines frozen ResNet50 features with a support-vector machine and reports confidence-aware results that you can download.

About

A research platform, not a medical device

NeuroInsight was built to study how well a classical machine-learning pipeline can separate four brain MRI categories. An ImageNet-pretrained ResNet50 turns each image into a feature vector, and an RBF support-vector machine turns that vector into class probabilities.

The model was trained and validated on an audited split of a public brain MRI dataset. The platform shows every class probability, warns when the model is uncertain, and never presents a result as a diagnosis. It keeps analysis records, not your images.

How it works

From an MRI slice to a prediction

  1. 1{{ icon('upload') }}

    MRI Upload

    A validated JPG, PNG or BMP image, up to 10 MB.

  2. 2{{ icon('image') }}

    Preprocessing

    Decoded as RGB and resized to 224×224 pixels.

  3. 3{{ icon('layers') }}

    ResNet50 Feature Extraction

    A frozen ImageNet ResNet50 produces 2048 features.

  4. 4{{ icon('workflow') }}

    SVM Classification

    An RBF SVM turns the features into class probabilities.

  5. 5{{ icon('circle-check') }}

    Prediction

    The most probable class, its confidence and a warning when needed.
